法院文书下载器 · 手机版

粘贴电子送达短信 / 链接，自动下载该案件全部文书（PDF）

使用说明 / 常见问题

使用步骤：粘贴短信 → 点「开始下载」→ 等待处理 → 点每份文书的「查看」预览或「下载」保存到手机。

「打包下载全部」会把整个案件的文书压缩成 ZIP，适合一次性保存到手机。

手机如何访问：电脑与手机连同一 WiFi，手机浏览器打开 http://电脑局域网IP:8000。长期远程使用请放到你的 HTTPS 域名（frp / workbuddy.link）后访问。

提示：电子送达链接有时效，若提示“清单为空/下载失败”，请重新从法院短信复制最新链接再试。

本工具仅供本人依法处理诉讼事务使用，请遵守相关平台与法律规定。
