# 官网网页（web/）

本目录存放「法院文书下载器」官网静态网页，部署在自有服务器（宝塔面板）。

## 文件

- `index.html` — 官网主页（版本号 / 下载链接 / 更新日志均通过 GitHub API 动态拉取，**发新版无需改动本文件**）
- `update_web.sh` — 宝塔面板更新脚本（计划任务用）

## 服务器部署（宝塔）

1. 宝塔面板 → 网站：确认已建好站点，记下网站根目录（一般是 `/www/wwwroot/xxx`）
2. 打开 `update_web.sh`，把 `WEB_DIR="/www/wwwroot/你的站点目录"` 改成实际根目录
3. 宝塔面板 → 计划任务 → 添加任务：
   - 任务类型：Shell 脚本
   - 任务名称：官网更新
   - 执行周期：每天凌晨 1 点（或任意周期；也可不设周期、需要时手动点「执行」）
   - 脚本内容：粘贴 `update_web.sh` 全部内容
4. 首次先手动点一次「执行」，确认日志输出「更新成功」

## 更新机制

- 网页版本信息实时来自 GitHub Releases API → **仓库一发新版，网页内容自动同步**
- 网页文件本身若需改动：改完后 commit/push 到本仓库 `web/` 目录，服务器上的计划任务（或手动执行）会自动拉到最新版
- 脚本内置双源容灾（GitHub raw + jsDelivr 镜像）、完整性校验、备份与原子替换，失败不会影响线上网页
